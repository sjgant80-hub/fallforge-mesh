FallForge Mesh — sovereign nodes, coupled

Layer 5 of the sovereign-node factory. Couple your owned nodes into a mesh where no single node — and not the borrowed frontier — dominates. Three walls: coupling health (perfect agreement is correlated, not verified), a shared frontier budget (the big model is one mesh-wide resource, not each node's default), and cross-verification by deterministic quorum — never an LLM judge. The frontier is a limb the mesh borrows, not an apex it serves.

The shared frontier budget

How the mesh stays sovereign

  1. No node is a private higher authority. The frontier limb is a shared, budget-bounded resource; the kernel spends it for the mesh, not for any one node.
  2. A second opinion must actually differ sometimes. Two nodes that always agree are correlated — the mesh calls that MERGED and refuses to trust it as verification.
  3. Verification is deterministic. Agreement is exact-match quorum on the structured answer; no judge model is ever asked "is this good?".
  4. The mesh never invents a specialist it lacks. An ask with no matching member routes to the shared limb, openly — not to a node pretending to cover it.
